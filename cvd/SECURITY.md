# Security policy

Do not place confidential vulnerability reports, patient information, production
credentials, or long-lived webhook secrets into the public/static deployment.

Report security issues privately to the repository owner. Do not open a public
issue containing exploit details, customer information, credentials, or an
unpublished vulnerability.

For live organizational use, deploy the authenticated backend described in
`docs/PRODUCTION.md`. The browser-only storage mode is suitable for evaluation,
training, and non-sensitive tabletop exercises.
