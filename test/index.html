Step 1 of 2 — connect to your model server

Paste your server address. In GitHub Codespaces this is the port-8000 forwarded address (Ports tab → copy), e.g. https://fuzzy-enigma-xxxx-8000.app.github.dev. Running locally it's http://localhost:8000.

Waiting to connect…
  1. Start the server: bash start.sh in your Codespace terminal.
  2. Set port 8000 to Public (Ports tab → right-click → Port Visibility).
  3. Paste the forwarded address above and press Connect.

Accepted formats
• .txt and .md — plain text and Markdown, the most reliable
• .pdf — text-based PDFs only (exported reports, policies). Scanned/image PDFs won't extract.
• Web links — public pages; the text is fetched and indexed. Pages behind logins won't work.
Word/Excel files: save or export as PDF or text first.
